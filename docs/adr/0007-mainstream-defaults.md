# ADR 0007: mainstream, reversible defaults

**Status:** accepted

**Decision.** Default to Dependabot (native, no app install; Renovate offered), Contributor Covenant 3.0, the MIT license, `main`, and **private** visibility.

**Rationale.** These are mainstream, native and reversible. Private beats public because making a repository public later is easy, while exposure cannot be undone. Every default is listed in the interview so the user can change it.
