# ADR 0009: the name `cutwater`

**Status:** accepted (2026-11-10)

**Context.** The implementation plan recommended `throughline`, subject to an M0 clash check, with `cutwater` as the fallback. The check on 2026-11-10 found `throughline` taken in the same space:
- npm `throughline` (0.17.0): persistent memory hooks for Claude Code, Codex, Grok and Cursor.
- `jrpease/throughline`: a Claude Code plugin.
- `cahenesy/throughline`: a Claude Code plugin with a phase-gate PR pipeline, the closest overlap.
- Several other agent-tooling repositories with the same name.

`cutwater` had no npm package, and only small, unrelated GitHub repositories.

**Decision.** Name the skill, plugin, helper and manifest `cutwater`: the forward edge of a ship's bow, which goes first and parts the water, like a skill that always runs setup first. The GitHub repository keeps its name, `YourAKShaw/ThroughLine`.

**Consequences.** The name needs a line of explanation, which the README gives. Installing it next to another `throughline` plugin cannot collide.
